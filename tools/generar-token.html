Marketing Digital Avanzado · UAO

Pega este mismo valor en los dos sitios:
1. Apps Script → Configuracion del proyecto → Propiedades de la secuencia de comandos → ADMIN_TOKEN
2. AWS Lambda → Configuration → Environment variables → API_KEY
Esta pagina no envia nada a ningun servidor: el token se calcula en tu navegador. Guarda la clave donde puedas recuperarla — el token no se puede revertir a la clave, asi que si la olvidas hay que generar una nueva y actualizarla en los dos sitios.
